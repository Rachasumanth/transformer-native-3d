# Lantern 01

Free 4K model of an antique brass/bronze hurricane lantern with textured glass globe, worn patina, metal handle and detailed rivets for vintage character.

Poly Haven reports 33902 polygons. Source asset: https://polyhaven.com/a/Lantern_01. Geometry is screened from the 1k glTF download; its original glTF, buffer, referenced textures and hashes are retained here.
